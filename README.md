# 🥇 بوت تداول الذهب XAU/USD — Gold Trading Bot

روبوت تحليل ذهب **احترافي وحتمي (Deterministic)** يقدم توصيات **السكالبينج (المضاربة اللحظية)** و**التداول اليومي** مع نسبة ثقة مدروسة مبنية على نظام أعمدة موزونة — بدون أي عشوائية.

A professional, fully deterministic gold (XAU/USD) trading analysis bot providing **scalping** and **day trading** recommendations with a mathematically derived confidence score — zero randomness.

---

## ✨ المزايا الرئيسية

| الميزة | الوصف |
|---|---|
| 🧠 **محرك Confluence بسبعة أعمدة** | اتجاه متعدد الأطر (24%) + زخم (20%) + جلسات (12%) + دعم/مقاومة (14%) + حركة سعر (10%) + ارتباط كلي (10%) + تقلب (10%) |
| 📊 **12 مؤشراً قياسياً** | EMA 9/21/50/200، RSI-14 (Wilder)، MACD، Bollinger Bands، ATR-14، Stochastic، ADX، VWAP |
| ⏱️ **5 أطر زمنية** | 5 دقائق، 15 دقيقة، ساعة، 4 ساعات، يومي — تُحلَّل كلها مع كل تحديث |
| 🌐 **وعي كلي** | مؤشر الدولار DXY (علاقة عكسية) + الفضة SI (علاقة موجبة) + تقويم الأخبار ForexFactory عالي التأثير |
| 🗺️ **هيكل السوق** | دعوم/مقاومات متجمعة، بيفوت يومي، فيبوناتشي، النطاق الآسيوي، كشف كنس السيولة (SMC Sweep) |
| 🎯 **مستويات صفقة كاملة** | دخول + منطقة، وقف خسارة مبني على ATR (1.35-2.2×)، 3 أهداف بمقاس RR |
| 🧮 **حاسبة لوت** | معادلة إدارة رأس المال: المخاطرة 1-2% لكل صفقة |

## 🧠 كيف تُحسب الثقة؟ (الشفافية الكاملة)

```
score = Σ(درجة_العمود × وزن_العمود) / 100        // من -100 إلى +100
direction = BUY إذا score ≥ +15 | SELL إذا ≤ -15 | WAIT غير ذلك
confidence = 50 + |score| × 0.45 × qualityGate    // سقف 95%
```

بوابة الجودة (qualityGate) تخفض الثقة تلقائياً في الحالات الخطرة:
- تقلب ميت (ATR تحت 70% من متوسطه) → ×0.78
- تعارض الاتجاه مع الزخم → ×0.82
- خارج جلسات السيولة (لندن/نيويورك) → ×0.88
- عمق بيانات غير كافٍ → ×0.85

> كل سبب في التحليل له مساهمة رقمية موثّقة تظهر في الواجهة — افتح أي عمود لترى الحساب بنفسك.

## 📚 المنهجية (مصادر القواعد)

محرك التقييم مبني على قواعد موثقة من أبحاث عميقة في سلوك الذهب الحديث (2024-2026) وكورس استراتيجيات الذهب المربحة:

1. **توقيت الجلسات** — ذروة الحركة الاتجاهية في تداخل لندن/نيويورك 13:00-17:00 GMT
2. **كسر النطاق الآسيوي** — إغلاق شمعة M15 خارج نطاق 00:00-07:00 UTC بعد فتح لندن، الهدف 1.5-2× عرض النطاق
3. **كنس السيولة (Judas Swing)** — كنس قمة/قاع النطاق الآسيوي قبل الحركة الحقيقية (مفاهيم Smart Money)
4. **ارتداد Bollinger + RSI** — اختراق الشريط + تشبع RSI + إغلاق داخل الشريط = ارتداد نحو المنتصف
5. **نظام EMA 50/200 الترندي** — التداول مع التيار فقط على H4، دخول على التصحيحات
6. **فيبوناتشي 50%-61.8%** — مناطق الدخول الذهبية مع الاتجاه (استراتيجية السكالبينج بالتصحيح)
7. **إدارة المخاطر** — 1-2% لكل صفقة، وقف 1.35-2.2×ATR، عائد/مخاطرة ≥ 1:2، اللوت = المخاطرة ÷ (مسافة الوقف × 100$)

## 🧠 التدريب الذاتي (Walk-Forward Blind Training)

البوت **يدرّب نفسه** على شموع حقيقية بتدفق أعمى (Walk-Forward): يتنبأ دون رؤية النتيجة ← يتحقق ← يفسّر لنفسه لماذا أصاب أو أخطأ ← يعدّل أوزان أعمدته ← يكرر.

| المقياس | النتيجة (تحليل أعمى على سنتين) |
|---|---|
| البيانات | **11,274 شمعة ساعة** حقيقية (2024-09 → 2026-09) — Yahoo GC=F |
| التنبؤات الأعمى | **37 صفقة مختارة بدقة** (لم يرَ نتيجتها أبداً قبل التنبؤ) |
| نسبة الفوز | **70.3%** (26 فوز / 11 خسارة) |
| عامل الربح | **2.21** | التوقع: **+0.361R** | أقصى تراجع: 2.05R فقط | أسوأ سلسلة: 2 |
| الاختبار الصارم | آخر 25% لم ترها حلقات التعلم: **62.5%** (لا فرط تجهيز) |
| أقوى استراتيجياته | بولينجر+RSI **91.7%** · انعكاس RSI **85.7%** · ارتداد دعم/مقاومة 73.9% |

الأوزان المتعلمة تُطبَّق تلقائياً على الإشارات الحية، والنموذج محفوظ في `trained-model.json` (يعمل على Vercel دون قاعدة بيانات):

```
trend:21.9 · momentum:21.3 · location:14.6 · priceAction:10.4 · macro:10.4 · session:11 · volatility:10.4
```

قواعد الربح المكتشفة من البحث والتحليل ومدمجة في المحرك: نافذة التداخل لندن+نيويورك (13–16 UTC بعد حذف ساعة 17 بفوزها 33%)، **دورة الأسبوع الخفية** (الاثنين نطاقات ميتة والأربعاء تشظٍ — إجماع 4+ إلزامي فيهما)، فخ لندن Judas Sweep، محاذاة EMA200، حرس RSI/ADX، معايرة الثقة المفرطة (سقف 90 بأوزان متناقصة العائد)، أهداف مخصصة لكل استراتيجية، وامتناع كامل عن التداول نهاية الأسبوع وأيام الأخبار عالية التأثير.

## 🛠️ التقنيات

- **Next.js 16** (App Router) + **TypeScript** + **Tailwind CSS 4** + shadcn/ui
- محرك التحليل: TypeScript خالص — دوال نقية (Pure Functions) بلا أي عشوائية
- مصادر البيانات (بدون مفاتيح API):
  - شموع الذهب: Yahoo Finance `GC=F`
  - مؤشر الدولار: `DX-Y.NYB` | الفضة: `SI=F`
  - تقويم الأخبار: ForexFactory (أحداث USD عالية التأثير)
  - الشارات: TradingView Embeds (OANDA:XAUUSD)
- تخزين مؤقت بالذاكرة 55 ثانية لتفادي حدود المعدل
